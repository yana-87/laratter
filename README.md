## 実装した内容

- プロフィール（自己紹介文）の編集・表示機能を追加した．

## デプロイ先の URL または画面収録したファイル名

40th_2025_phase01.mov

## 操作手順

1. 画面右上部のナビゲーションから「Profile」をクリックし、プロフィール編集画面に移動する．画面下部に自己紹介文の編集フォームが表示されている．
2. テキストエリアに任意の自己紹介文を入力し、「保存」ボタンをクリックする．
3. 保存後、マイページに移動すると、アカウント作成日時の下に新しい自己紹介文が表示されていることを確認できる．
4. Tweet一覧画面で投稿者の名前をクリックすると、各投稿者の自己紹介文を確認できる．

## 工夫した点

- old()を使用して現在の自己紹介文が編集フォームにも表示されるようにした．
- 自己紹介文編集フォームのスタイルを周りと統一した．

## 苦戦した点

- 当初、fillableにカラムを追加するのを忘れており、データベースに保存することができていなかった．
